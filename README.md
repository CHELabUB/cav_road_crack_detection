#  Infrastructure-guided connectivity-enhanced road crack detection and estimation

This repo is made for documenting the code for our [paper](https://www.computer.org/csdl/proceedings-article/most/2026/618200a193/2gNOZvXt4Iw)

## Required by all applications

You are welcome to test our pipeline on your own cv2x vehicle which supports the usage of Commsignia APIs for the CV2X device. Here we list the necessities for the software stack:\
Python 3.10 \
ROS2 humble \
Commsignia APIs (need license)

For details of our detection pipeline, please read our [README](/detection_pipeline/README.md) in [detection pipeline](/detection_pipeline/)\
For details of our inference models, please read our [README](/Inference_models/README.md) in [inference_model](/Inference_models/)\
Feel free to try our length estimation example standalone in [length_estimation_example](/length_estimation_example/)
