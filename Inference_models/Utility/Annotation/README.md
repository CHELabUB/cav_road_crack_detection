### Annotation
Tool developed by @Yamini-26 to annotate crack test data. 

#### Manual annotation
Manual annotation script [crack_annotation.py](../../LECSFormer/datasets/crack_annotation.py).

A video instruction can be found [here](https://buffalo.box.com/s/qjvgylk5fyrf3ht6ovtcffpiuawf219a).

#### Detection + Refine Annotation

The mask is generated by edge detection (program and instructions to be added), and [annotation_refine.py](annotation_refine.py) is used to refine the annotation manually.

Some annotated examples can be found [here](https://buffalo.box.com/s/4revaswpr0srogqcggfjab5hvr2ci0m9).

A video instruction on how this can be used can be found [here](https://buffalo.box.com/s/ngodc0ubzutnd6r0qcj1bc7s6h7uek0q).
